# Northstar — server-ready snapshot, 2026-10-03

Самостоятельная копия текущего проекта. Предыдущая версия в корне репозитория
не заменена. Исходники активной локальной установки также не менялись.

Серверная установка: [Trading_Terminal/SERVER.md](Trading_Terminal/SERVER.md).

В этой поставке нет секретов, баз, личной торговой статистики, кэшей котировок
и локальных резервных копий. Список инструментов и описания стратегий сохранены;
Для регрессионных тестов приложены только публичные OHLCV-свечи, без сделок и сигналов.
графики загрузят данные из публичных источников. Перенос базы выполняется отдельно,
не через GitHub. Сервер и локальный тест используют разные базы и балансы.

Изменён инфраструктурный слой: Node/SQLite, защищённый HTTP-доступ, постоянное
хранилище, резервное копирование, независимые циклы сканирования/сопровождения.
Торговые стратегии, фильтры, TP/SL и риск-политика не пересматривались.

Это сборка для серверного paper-теста, не допуск к реальным деньгам. Известные
ограничения стратегии и восстановления минутной истории после простоя остаются.
Скальпинговый WebSocket-контур по-прежнему зависит от открытой вкладки браузера;
эта поставка НЕ превращает его в автономный серверный скальпер.

Python-боты в корне сохранены как исходники; контейнер их не запускает.
