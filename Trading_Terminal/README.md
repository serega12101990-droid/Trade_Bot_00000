# Northstar Trading Terminal

Локальный терминал для визуального анализа торговых идей. Первая версия работает только в режиме чтения: она не отправляет ордера и не меняет настройки действующего бота или виджета.

## Как запустить

Дважды щёлкните `START_TRADING_TERMINAL.cmd` в Проводнике. Не запускайте `.cmd` кнопкой «Run Python» — это командный файл Windows, а не Python-код.

Если запускаете из VS Code кнопкой Python, используйте `START_TRADING_TERMINAL.py`. Оба варианта обновляют локальные данные и открывают терминал в браузере. Если порт 3000 занят, запускатель безопасно выберет следующий свободный порт.

Первый запуск после обновления может занять 20–45 секунд: в это время собираются компоненты графика. Не закрывайте окно до сообщения `Trading Terminal открыт`.

Если терминал уже открыт и нужно только перечитать свечи, сигналы и журнал, запустите `REFRESH_TERMINAL_DATA.cmd`, затем обновите страницу в браузере.

## Что уже работает

- базовая тестовая база: 5 криптовалют и 20 акций США из избранного виджета;
- ручное добавление и удаление тикеров криптовалют, акций США и российских акций MOEX через кнопку `+`, с фильтрацией и сортировкой списка;
- свечные графики на 15м, 30м, 1ч, 4ч, 1д и 1н;
- перемещение графика ЛКМ по горизонтали и вертикали, масштаб колёсиком и кнопки навигации;
- масштаб цены перетаскиванием правой шкалы, плотность свечей перетаскиванием нижней шкалы и изменение высоты MACD через разделитель;
- переключаемый часовой пояс графика и часы Москвы, Лондона, Нью-Йорка и Гонконга;
- автоматическая подгрузка свежих свечей выбранного инструмента: каждые 30 секунд для криптовалют и каждые 2 минуты для акций;
- автоматическое обновление котировок всех инструментов в списке слева (OKX для криптовалют, Yahoo для акций США, MOEX ISS для российских акций);
- отображение текущей формирующейся свечи отдельно от завершённых свечей;
- перекрестие курсора с точной ценой на правой шкале и временем на нижней шкале, включая область будущего;
- EMA 20/50/200, объём и MACD 12/26/9;
- визуальный слой EMA-коридоров («дыр»);
- СИГНАЛ → КОНТЕКСТ → ТОЧКА ВХОДА с понятными уровнями «Вход», «Цель прибыли» и «Отмена идеи / стоп» из локального сканера;
- автоматическое скрытие уровней устаревших сценариев, чтобы старые Entry/TP/SL не выглядели как действующая сделка;
- сценарный прогноз на несколько свечей вперёд: рост, боковик и снижение с весами, диапазоном неопределённости и проверкой похожих состояний на истории;
- постоянный журнал прогнозов: версия модели, исходные показатели, веса сценариев, цель, отмена и полный снимок расчёта;
- автоматическая оценка после завершения горизонта: направление, фактическая доходность, касание цели/отмены, максимальное отклонение, ошибка цели и Brier score;
- базовое распознавание свечных подтверждений Нисона;
- экспериментальный уровень 50% длинной импульсной свечи;
- отдельные статусы рабочих, исследовательских и черновых стратегий;
- импорт CSV сделок и отображение входов выбранного тикера на графике;
- разделы «График», «Сделки» и «Стратегии».

## Источники данных

Терминал читает локальные кэши из `trading_platform/data`, идеи из `trading_platform/logs/current_entry_watchlist.json`, результаты исследований из `trading_platform/logs` и журнал бота `logs/trades_stats_v7.csv`. После открытия выбранный тикер и таймфрейм автоматически дополняются свежими публичными свечами Bybit/OKX, Yahoo или MOEX ISS; API-ключи для этого не нужны. Если сеть временно недоступна, график продолжает работать на локальном кэше и показывает предупреждение у названия источника.

Для MOEX доступны таймфреймы 15м, 30м, 1ч, 4ч, 1д и 1н. Сценарные прогнозы учитывают официальный календарь российского фондового рынка на 2026 год, включая дополнительные сессии выходного дня. Публичные данные ISS могут поступать с задержкой и не предназначены для исполнения реальных заявок. Прогнозы MOEX сохраняются в журнале, но виртуальные сделки пока не смешиваются с бумажным счётом в USDT: для этого нужен отдельный RUB-счёт.

Если `iss.moex.com` открывается только через браузерное расширение VPN, локальный сервер терминала этот VPN не использует. Для загрузки российских свечей нужен VPN для всей Windows либо локальный HTTP-прокси, доступный серверу. В строке над графиком показаны фактическое количество и диапазон загруженных свечей; терминал запрашивает до 1000 итоговых свечей на каждый таймфрейм.

Журнал прогнозов хранится в постоянной локальной базе терминала. Один и тот же прогноз для одной версии модели, тикера, таймфрейма и закрытой свечи записывается только один раз. После появления необходимого количества завершённых свечей запись автоматически получает результат; исходные параметры прогноза при этом остаются неизменными. Статистика доступна во вкладке «Прогнозы».

Для американских акций 4-часовые свечи собираются из часовых, недельные — из дневных. Криптовалюты используют готовые кэши соответствующих таймфреймов.

В шапке инструмента показана последняя доступная цена выбранного таймфрейма. Если свеча ещё не закрылась, она явно подписана «Формируется»; сигналы локального сканера по-прежнему рассчитаны только по завершённым свечам. При наведении на график строка OHLC подписывается как «Курсор», справа отображается цена перекрестия, а внизу — соответствующие дата и время. В списке слева показываются свежая цена и суточное изменение; время последнего успешного обновления находится под списком.

Уровни сценария не означают, что терминал открыл позицию: «Вход» — предполагаемая зона входа, «Цель TP1» — первая цель фиксации прибыли, «Отмена SL» — уровень, после которого идея считается неверной. Старый сценарий автоматически переводится в архив и его линии скрываются до нового запуска анализа.

Управление графиком: перетаскивайте центральную область ЛКМ для движения по времени и цене. При включённом слое «ПРОГНОЗ» справа автоматически открывается закреплённое «Пространство сценария». В нём сплошной линией показан основной маршрут, пунктиром — альтернативные, полупрозрачной зоной — диапазон неопределённости. Это модельные траектории, а не выдуманные будущие свечи. Ширину пространства можно менять перетаскиванием левой границы или кнопками «Сценарий +/−». Правую шкалу цен перетаскивайте для вертикального сжатия/растяжения; нижнюю временную шкалу — для горизонтального сжатия/растяжения; линию над MACD — для изменения высоты зоны индикатора. «Сброс вида» возвращает автоматический масштаб и исходные размеры.

## Ограничения первой версии

- котировки и свечи обновляются с задержкой публичных источников и не являются биржевым потоком для исполнения ордеров;
- расписание MOEX на годы после 2026 потребует обновления по новому официальному торговому календарю;
- исследовательские стратегии не считаются готовыми к реальной торговле;
- оценка совпадения факторов не является гарантией сделки или прибыли;
- управление ордерами намеренно отключено.
